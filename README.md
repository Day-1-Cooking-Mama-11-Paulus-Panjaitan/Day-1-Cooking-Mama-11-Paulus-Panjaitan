# Day-1-TIK-Mengajar-Workshop-Git-Github_Paulus-Panjaitan

Sosialisasi TIK Day 1 Workshop GitHub

Nama Peserta: Paulus Panjaitan

Kelompok: (Cooking Mama)

Deskripsi Singkat: Mempelajari dasar penggunaan AI, Prompt Engineering, Git, dan GitHub.

Tujuan: Memahami cara membuat prompt AI yang baik dan spesifik serta mempelajari penggunaan Git dan GitHub untuk mengelola perubahan file, menyimpan proyek, dan melakukan kolaborasi.

Rangkuman Materi

Materi ini membahas dua topik utama:

Prompt Engineering: Cara membuat instruksi atau perintah yang jelas kepada AI agar menghasilkan jawaban yang sesuai kebutuhan. Dalam membuat prompt, ada empat bagian penting yaitu Role, Task, Context, dan Format.
Git dan GitHub: Git digunakan untuk mencatat dan mengelola perubahan pada file atau kode, sedangkan GitHub digunakan untuk menyimpan repository secara online dan memudahkan kerja sama dengan orang lain.

Materi juga membahas dasar Git Workflow yang terdiri dari Working Directory, Staging Area, dan Git Directory. Selain itu, dipelajari beberapa perintah dasar Git seperti `git init`, `git add`, `git commit`, `git push`, dan `git pull`.

Selanjutnya, materi mencakup cara menginstal dan mengatur Git, menghubungkan VS Code dengan Git, membuat repository di GitHub, serta mengenal SSH Key untuk menghubungkan komputer dengan akun GitHub.

Kesimpulan: Dari workshop ini, saya jadi lebih memahami cara menggunakan AI dengan prompt yang tepat serta mengetahui dasar penggunaan Git dan GitHub untuk menyimpan, mengelola, dan mengembangkan proyek.
